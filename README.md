# Emotion Detection Application

This repository contains the final project for the embedded AI course.

## Project Details
- **Project Name:** Emotion Detection Application
- **Description:** A Flask-based web application that utilizes the Watson NLP library to analyze the emotional tone of text. It identifies emotions such as anger, disgust, fear, joy, and sadness, and determines the dominant emotion.

## Features
- **Emotion Analysis:** Connects to Watson NLP API for text sentiment and emotion analysis.
- **Web Interface:** A Flask server providing a simple web interface for user input and result display.
- **Error Handling:** Gracefully handles empty inputs and API errors.
- **Unit Testing:** Comprehensive unit tests included.
- **Code Quality:** Static code analysis optimized to a perfect 10/10 Pylint score.
